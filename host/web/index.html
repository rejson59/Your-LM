PRZYGOTUJ WINDOWS

Odzyskaj pamięć przed modelem

YourLM pokazuje programy bieżącego użytkownika z widocznymi oknami i wstępnie zaznacza największe bezpieczne pozycje. Odznacz wszystko, czego nie chcesz zamykać. Procesy systemowe, zabezpieczenia, instalatory, terminale, programy administratora oraz YourLM są chronione. Zapisz pracę przed zamknięciem.

Nic nie zaznaczono.
Kliknij „Sprawdź aplikacje”, aby zobaczyć przybliżony RAM widocznych programów.
Przycisk wysyła standardowe WM_CLOSE — nie zabija procesów. Program z niezapisanym dokumentem może wyświetlić własne pytanie i pozostać otwarty. Pamięci systemu, sterowników i cache Windows nie da się bezpiecznie wyzerować.

WYKRYTE URZĄDZENIA
